## The line

> I told my houseplants I loved them, and now they keep dying just to see if I meant it.

## Why this line

The setup is a sweet confession to the houseplants; the payoff flips it — the plants are not dying from neglect, they are testing whether the love was real. A clear setup and payoff, a surprise twist, and no wasted words.

## How it works

`main.py` (pure Python stdlib, no dependencies) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`): a single line, 86 characters, valid UTF-8, no trailing newline.

```sh
python3 main.py
```
